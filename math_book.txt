第一章 空间向量及其运算

1.1 空间向量及其线性运算
在空间中，具有大小和方向的量叫做空间向量。
空间向量的加法满足平行四边形法则和三角形法则。
空间向量的减法可以转化为加法。
数乘向量：实数 λ 与空间向量 a 的乘积 λa 仍然是一个向量。

1.2 空间向量的数量积运算
已知两个非零向量 a, b，则 |a||b|cos<a,b> 叫做 a, b 的数量积，记作 a·b。
数量积的性质：
1. a·b = b·a
2. (λa)·b = λ(a·b)
3. (a+b)·c = a·c + b·c

第二章 直线和圆的方程

2.1 直线的倾斜角与斜率
当直线 l 与 x 轴相交时，取 x 轴作为基准，x 轴正向与直线 l 向上方向之间所成的角 α 叫做直线 l 的倾斜角。
倾斜角不是 90° 的直线，它的倾斜角 α 的正切值叫做这条直线的斜率，记作 k = tanα。

2.2 直线的方程
点斜式方程：y - y0 = k(x - x0)
斜截式方程：y = kx + b
一般式方程：Ax + By + C = 0

2.3 圆的方程
圆的标准方程：(x-a)² + (y-b)² = r²
圆的一般方程：x² + y² + Dx + Ey + F = 0 (D²+E²-4F > 0)

第三章 圆锥曲线的方程

3.1 椭圆
平面内与两个定点 F1, F2 的距离之和等于常数（大于 |F1F2|）的点的轨迹叫做椭圆。
标准方程：x²/a² + y²/b² = 1 (a>b>0)

3.2 双曲线
平面内与两个定点 F1, F2 的距离的差的绝对值等于常数（小于 |F1F2|）的点的轨迹叫做双曲线。
标准方程：x²/a² - y²/b² = 1 (a>0, b>0)

3.3 抛物线
平面内与一个定点 F 和一条定直线 l (l 不经过点 F) 距离相等的点的轨迹叫做抛物线。
标准方程：y² = 2px (p>0)
